# Ravichandra Bodduri — Portfolio

A responsive React portfolio built with Vite, Material UI, and Framer Motion.

## Requirements
- Node.js 18+ (Node 20 LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open a terminal in the extracted `ravichandra-portfolio` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Customize
- Edit project and experience content in `src/App.jsx`.
- Update colors and typography in `src/main.jsx` and `src/styles.css`.
- Update contact details and social links in `src/App.jsx`.
- To add your own resume PDF, place it in `public/` and add a download link/button where desired.

## AI Build Lab

The portfolio now includes an **AI Build Lab** designed around a practical modern development workflow:

**Idea → Figma → AI planning → Cursor implementation → Testing → Deployment**

The interactive Project Builder runs entirely in the browser and generates a reusable master prompt for ChatGPT, Claude, or Cursor. It does not require an API key and does not send the entered project information anywhere.

The builder helps structure:
- Product requirements
- User roles and flows
- Screen list
- Figma design specification
- React.js / React Native architecture
- API and data planning
- Milestone-based implementation
- Testing and edge cases

The portfolio also includes quick links to Figma, ChatGPT, Claude, and Cursor.


## Full-Stack AI Build Lab update

The AI Build Lab now reflects a full-stack workflow rather than a frontend-only workflow.

It covers:
- React.js and React Native

- MySQL database design and SQL
- Java REST API learning/equivalent implementations
- Authentication and role-based authorization

The generated master prompt explicitly asks AI to produce database design, REST API specifications, PHP implementation guidance, Java equivalents for learning, frontend architecture, integration details and test checklists.
